Bedienung ausprobieren

Übungsmodell mit Beispielwerten – klicke im Bild auf Tasten (TRACK, PAN, EQ, SEND, PLUG-IN, INST, F1–F8, SHIFT, CANCEL) und auf REC oder SELECT eines Kanalzugs. Das echte Gerät zeigt das Dashboard live.

Schnell ausprobieren

Gelb leuchtend = Taste aktiv. Unter jedem Regler: ↓ = was Drücken bewirkt. Die Pegel-LEDs unter den Displays laufen immer mit dem Kanalpegel.
